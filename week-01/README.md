# Semana 1 — Diagramas UML

**Tema:** Conceptos generales, orientación a objetos y UML.

**Tarea:** Modelar el proceso «traslado o alta del paciente con liberación consistente de cama»: diagrama de casos de uso (actores y objetivo), diagrama de actividad (decisiones, excepciones y resultado) y diagrama de secuencia (participantes, mensajes, validaciones y respuesta), manteniendo trazabilidad entre los tres.

**Entregable:** UML de casos de uso y narrativa de alcance.

## Contenido

- `diagramas/` — casos de uso, actividad y secuencia (`.puml` editable + `.png`/`.svg` renderizado)
- `documento/InformeUML.docx` / `.pdf` — informe final
- `trazabilidad/` — matriz de trazabilidad, requisitos y excepciones
- `defensa/guia-defensa.md` — guía para la exposición oral
- `evidencia/` — referencia de Git y estructura del repositorio

Contenido replicado desde el repositorio grupal (PR #67) y desde el repositorio personal [`uml-asii-08-traslados-altas-camas`](https://github.com/00AbiMendoza/uml-asii-08-traslados-altas-camas), donde se desarrolló originalmente.
