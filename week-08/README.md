# Semana 8 — Diseño de experiencia de usuario

**Tema:** Diseño de experiencia de usuario.

**Tarea:** Diseñar el flujo UX de «traslado o alta del paciente con liberación consistente de cama» por sus roles autorizados. Incluir inicio, decisión, confirmación, estados vacío/carga/éxito, errores recuperables, ayuda contextual y protección de datos.

**Entregable:** User flow por rol y 4-6 wireframes anotados con estados, mensajes, validaciones y reglas de interacción.

## Contenido

- `semana-08-diseno-ux.md` — documento completo con la cobertura de cada elemento pedido
- `flujo-ux-por-rol.puml` / `.png` — user flow (los 4 roles comparten el mismo flujo; el permiso se valida por rol)
- `w1-inicio.png` a `w6-alta-ayuda-contextual.png` — 6 wireframes anotados (inicio, decisión, formulario de traslado en estado vacío, carga/éxito, error recuperable, formulario de alta con ayuda contextual y protección de datos)

Cada wireframe y cada estado corresponde a un requisito, regla de negocio o criterio de aceptación real ya validado en el backend (`ESPECIFICACION.md`) — no son suposiciones de diseño.
