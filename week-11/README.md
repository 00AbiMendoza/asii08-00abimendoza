# Semana 11 — Mejores prácticas para diseño móvil/web

**Tema:** Mejores prácticas para diseño móvil/web.

**Tarea:** Construir un prototipo navegable desktop y móvil del flujo principal de Traslados, altas y liberación de camas, cubriendo camino feliz y un error crítico; mantener consistencia de roles, estados y accesibilidad.

**Entregable:** Enlace o archivo del prototipo, mapa de navegación y capturas desktop/móvil del camino feliz y del error crítico.
